Qaxiom Desktop

논문 참고문헌, 연구 노트, 수식(KaTeX/MathJax), Wiki를 로컬에서 관리하고 내 PC에 설치된 codex / claude CLI 세션으로 바로 분석·편집하는 데스크톱 앱입니다.

기존 브라우저 웹앱 서비스는 종료되었으며, 현재 Qaxiom은 로컬 CLI와 직접 연동되는 Electron 데스크톱 앱으로 제공됩니다.
최신 데스크톱 버전 다운로드 (GitHub Releases) GitHub 저장소 보기

1. CLI 설치 및 로그인

사용 전 내 PC에 codex 또는 claude CLI가 설치되고 로그인되어 있어야 합니다. (예: 터미널에서 codex login)

2. 데스크톱 앱 실행

설치한 Qaxiom Desktop 앱을 실행하면 로컬 CLI 인증 상태를 자동으로 확인하고 세션을 연결합니다.

3. 논문 첨부 및 노트 편집

Research Note에서 Add reference로 PDF/Markdown을 연결하고 Chat 질문 결과를 Diff로 검토해 반영할 수 있습니다.
