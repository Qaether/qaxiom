- 사이드바 레퍼런스 검색 패널에서 UTF-8 Markdown/TXT 등록, 파일당 2 MB 제한과 빈 파일·바이너리·미지원 형식 거부
- 불변 source ID, 원문 SHA-256, 추출기 `text-v1`, 외부 문헌/메모/자체 문서 역할 보존
- 동일 원문 hash의 중복 등록 방지 및 source·span 저장 실패 시 원자적 롤백
- 원문의 CRLF·UTF-16 문자 범위·행 위치를 유지하는 `ReferenceSpan`, 최대 2,400자 분할 시 surrogate pair 보존
- 정본과 정확히 같은 원문을 자체 문서로 연결하고, 레퍼런스 등록 후 정본이 생성된 경우도 검색 시 다시 확인
- 선택 문서만 대상으로 Web Worker BM25 검색, NFKC/소문자 단어와 한글 2-gram 기준선, 빈 결과 안내·검색 중단
- 검색 후보 중 근거 선택, 모델·질문·실제 전송 발췌 미리보기 후 명시적 전송
- 근거 최대 8개·12,000자 제한과 RAG 대화/근거 직렬화 48 KB 안전 한도, 초과 시 원문 자동 절단 없이 요청 차단
- 원문을 신뢰하지 않는 인용 데이터로 전달하며 문서 내 지시와 시스템 지시 구분
- 답변에 버전 고정 ContextBundle 보존, 중단·실패 후 재시도에서도 동일 근거 유지
- `[[R1]]` 형식의 인용 ID 연결 확인, 없는 번호와 완료 답변의 인용 누락 경고
- 인용 버튼에서 원문 hash/발췌 일치를 확인하고 전체 원문의 정확한 구간 강조
- 대화 Markdown 내보내기와 백업 동반 Markdown에 전송 근거·위치·hash 포함
- Dexie v3 레퍼런스 테이블 추가, 백업 v3 및 v1/v2 복원 호환성, 복원 전 원문·span·인용 참조 검증

이는 R2 전체 수용 기준 달성은 아니다. 부모 문맥·선택 ResearchContract·합성 검색 회귀 평가는 아래 후속 구현에서 완료했다. 프로젝트별 허용 자료·개정 계보/과거 버전 기본 정책, 모델별 토큰 예산, 실제 문헌 품질 평가와 대용량 측정은 남아 있다. 원문과 인용 연결은 확인하지만 의미적 지지·이론 정합성·프롬프트 주입의 완전 차단은 보증하지 않는다. BM25의 한국어/영어 간 의미 검색·임베딩과 자동 검토는 미구현이다.

OCR은 미구현 과제가 아니라 제품 비목표다. `ocr_required` 상태는 기존 데이터 호환성과 텍스트 추출 불가 표시를 위해 유지한다. 암호 입력/해제, 저자/논문 제목 메타데이터 추출, 복잡한 수식·다단/표의 의미적 재배열과 좌표별 인용 강조는 미구현이다. 수학 표현 fixture는 단순 텍스트 수식이며 실제 논문의 복잡한 수식 정확도를 검증한 것으로 간주하지 않는다. 배포·GitHub Actions·실제 모델 호출은 수행하지 않았다.

### R2 문맥·평가 단계 — 부모 구간과 필수 연구 기준

- 사용자가 선택한 검색 근거를 먼저 보존한 뒤 ATX 제목의 상위 제목·가장 가까운 섹션을 원문 span으로 회수; fenced code의 제목은 구조로 오인하지 않음

### 오류 처리

- 공급자 HTTP 오류를 대화 내 오류 메시지로 변환
- Gemini 인증 실패, 모델 없음, quota 초과 일부 분류

- 공급자 공통 SSE 파서에서 CRLF/LF 이벤트 경계, 멀티라인 `data`, comment, UTF-8 청크 분할과 마지막 잔여 버퍼 처리
- 잘못된 JSON 이벤트를 조용히 버리지 않고 명시적 오류로 전환
- OpenAI `error`/`response.failed`, Anthropic/Gemini 스트림 오류 payload 처리
- 스트리밍 중단을 오류와 구분하고 기존 부분 응답 보존
- 정상 종료된 빈 응답을 명시적인 재시도 가능 오류로 전환
- 네트워크/공급자 오류에서도 이미 생성된 텍스트와 오류 안내를 함께 보존
- 마지막 중단·오류 응답에만 재시도 제공
- 재시도 시 사용자 질문을 복제하지 않고 실패한 assistant 응답만 교체
- 중복 과금을 방지하기 위해 자동 재시도는 사용하지 않음

공급자 공통 HTTP 오류 분류와 연결 복구 정책이 남아 있어 출시 완료 상태는 아니다.

## Phase 5 명시적 폴더 백업 초판 (2026-10-03)
