# 서비스 완성 요구사항 감사

사용자 목표: 서비스를 완성하고 마지막에 기능 테스트를 완료한다. 커밋·푸시·배포·OCR은 수행하지 않는다. GitHub Actions 적용도 기존 지침대로 보류한다. 일부 단계의 통과를 서비스 전체 완료로 바꾸지 않는다.

이 표는 `IMPLEMENTATION_PLAN.md`와 `RAG_DESIGN_PLAN.md`의 범위를 유지한 작업 목록이다. 목표 완료 전 각 행의 요구사항·실패 흐름·회귀 테스트·실제 결과를 다시 감사한다.

외부 대조 전용 프로젝트 허용 정책(scope=external_review)은 후보/준비/예약/전송 전후/새 관계 승인과 정책 변경 실패 처리를 검증했다. 사용자가 명시적으로 확장한 research 정책은 정본 기반과 정본 선택 전 프로젝트 RAG 검색·원문/질문 임베딩·벡터 게시에 적용한다. v19는 기존 v1–v18 백업을 읽고 genuine v18 이력에 프로젝트 단독 범위를 소급 부여하지 않는다. 프로젝트/정본을 둘 다 고르지 않은 작업공간 전체 검색·임베딩과 내부 검토에는 프로젝트 정책이 적용되지 않는다. 정책 본문 전 개정 원장·접근 제어·프로젝트 격리 전체의 완료 증거는 아직 없다.

프로젝트 문서 조직 기반은 이름 변경·이동/분리·대표 지정·충돌/롤백·다중 문서 백업과 reload E2E를 통과했다. 조직 변경은 문서 버전/기준/검토를 합치지 않으며 해당 조직 단계에는 별도 스키마 버전을 추가하지 않았다. 현재 전체 스키마는 연구 기준의 명시적 정본 블록 연결을 포함한 v22이다. 프로젝트 허용 목록은 외부 대조 및 명시적 정본/프로젝트 RAG·임베딩에 연결했다. 교차 프로젝트 연결은 양쪽 현재 채택 주장에 대한 사용자 승인 후보 기록이며 자동 의미 통합이나 LLM 근거가 아니다. 자료 개정 정책/의미 기반 개념 통합은 남아 프로젝트 통합 전체를 완료로 판정하지 않는다.

R5 미선언 수정 영향 어휘 후보: 검증된 수정 전후 용어를 로컬 Worker로 탐색하고 후보 원문·일치 사유·미표시 개수를 공개한다. 사용자 선택 후 기존 범위/현재 승인 전제를 지정하며 API/관계 승인/Issue 해결은 자동 수행하지 않는다. 원문/승인 변경·위조·한도/취소/시간 초과 단위 검증과 실제 Worker E2E 통과. 어휘 후보 초판은 구현되었으나 의미 의존성/수식 동치·실제 재현율·대용량 증거는 부족하므로 위 관계 행의 미선언 영향 수용 기준은 완료로 바꾸지 않는다. 후보 UI는 임시 상태이며 이 기능 자체는 스키마 변경을 추가하지 않았다. 현재 전체 스키마/백업은 연구 기준 원문 블록 연결의 v22이다.

현재 판정: **목표 진행 중, 서비스 전체 완료 아님**. 실제 API 검증은 사용자가 제공한 허용 키/계정이 있어야 하며 현재 테스트는 모의 응답이다. 이는 다른 로컬 기능 구현을 중단할 이유가 아니다. 외부 호출 권한·계정이나 실제 문헌 라벨이 필요해지면 해당 증거를 요청하고 이미 가능한 작업을 계속한다.
